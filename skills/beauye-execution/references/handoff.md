# 页面方案交接

本 Skill 可以独立接收任何具备必要信息的页面方案。方案描述设计意图，不能作为实测证据。

接收任务、对象、必需和同时可见信息；区域与阅读顺序、操作位置；视觉层级、密度、组件与素材；交互、状态、视口与降级；具体参考、取舍、假设和待验证项。缺项时先查看已有页面与用户要求，补足当前任务需要的决定。

修改范围、检查范围及各自来源、项目条件、页面清单、规则版本统一放入任务记录。方案可以引用该记录，避免同步维护两份清单。

新增类型或明显改变区域、阅读顺序、主要操作位置和视觉权重时，先形成方案。图标或同组间距的小改动可引用已有方案。兼容的业务组件与现有设计变量优先，新增技术默认不授权迁移存量项目。

纯设计交付方案。纯评审交付问题、影响与建议。已授权实现继续完成代码和验证；验收问题需要改变设计关系时修订方案，再复查当前结果。

设计部分没有安装时也能使用本 Skill；它不要求读取仓库外的其他 Skill、个人资料或知识库。浏览器、图片和命令执行沿用宿主已有能力与授权。
