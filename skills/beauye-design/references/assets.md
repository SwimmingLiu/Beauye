# 图标与素材

素材服务识别、扫描、操作或实际视觉内容。标题和段落按识别需要使用图标，无素材需求时无需生成图片。

先确定图形帮助用户识别什么。文件名、类型和操作已经表达清楚的内容，不再附加用途口号、教学页脚、标题徽标或插画底板；空状态保留状态、恢复动作和必要条件。现有插画满足用途时直接复用，按实际展示尺寸检查，不为增加视觉元素重复生成。

指标卡中的图标与底纹辅助区分指标，数值仍由真实 DOM 表达。简单业务符号用已有 SVG，不为复用图片而保留宽横幅、空白底板或额外宣传区。图形加载失败或被移除时，指标名称、数值和操作仍完整。

管理区域只保留完成当前任务所需的工具与列表。旧页面已有的分类侧栏、视图切换、排序、统计计数和重复标题，须由当前任务证明必要性；仅要求查找和逐项操作时，删除这些额外区域及其占位，用一个工作区呈现搜索、上传与素材列表。必要的结果变化可通过状态播报表达，不自动新增常驻计数。

文件名已有扩展名时，类型图标和额外类型字段仅保留一种有识别价值的补充，避免扩展名、图标、类型列三次表达相同信息。大小和更新时间等有识别价值的内容保留，窄屏可在同一行元信息内组织。实验样例的来源记录在实验报告；输入中的 sample 标记不自动变成每行「示例」徽章、额外说明或常驻区域。

## 选择表达

- 通用界面动作：优先复用 Lucide 等项目既有 SVG 图标库，用于搜索、筛选、编辑、关闭、展开、上传等动作。库中已有且满足需求时直接复用。
- 简单业务图形：优先编辑已有矢量，必要时定制 SVG，用于业务符号、品牌标识、简单示意及需要精确缩放或动态控制的图形。
- 复杂视觉素材：用 imagegen 生成位图，用于复杂业务图标、插画、空状态配图、产品图片和背景。

特殊分层风格的项目参考为 [kubai-icons](https://github.com/kubai087/kubai-icons)。它是图标绘制工具，不替代 Button、Tooltip 或业务交互。其[许可证](https://github.com/kubai087/kubai-icons/blob/master/LICENSE)区分生成资产、示例图标与工具再分发；本包只引用项目与许可边界，不安装、复制或改写其 Skill、prompt 或引擎。

熟悉且含义明确的动作可纯图标表达；需要解释的动作使用图标与文字。主要操作和含义不明确的动作保留文字。

删除、编辑、搜索和星标等熟悉动作优先用 SVG 图标按钮，以提示和可访问名称补充含义，避免重复堆叠文字。emoji、颜文字与文字字符不充当界面图标；设置行等已有清楚名称的内容不自动附加装饰图标。

## 图标一致性与可访问性

同类图标统一尺寸、线宽、对齐和状态样式，优先使用已有封装。SVG 包装提供明确尺寸、原始 viewBox、fill/stroke 和 currentColor；避免样式缺失时回到默认大画布或实心黑块。简单形状只调整必要几何，复杂图形先检查是否已有合适 SVG，再决定 imagegen。

纯图标动作使用真实 button 或具有下载语义的链接，可访问名称说明动作和对象，例如「星标 文件名」。切换按钮保持名称稳定，用 aria-pressed 暴露状态，并以空心／实心等形状变化补充颜色。SVG 从可访问树隐藏，装饰图标避免重复朗读。

提示在鼠标悬停和键盘聚焦时可见，触屏可通过聚焦或轻触获得；提示不能遮挡名称、相邻按钮或焦点。触屏命中区域建议至少 44 × 44 px，图形本身可更小。保留 Enter、Space、可见焦点和清空／关闭后的焦点返回。

## 资源与业务行为

带图标的管理页必须完成搜索、筛选、星标、重命名、上传和下载等已授权行为；静态外观不能代替交互。引用的本地脚本与样式须在同次交付中存在，恢复已有未完成页面时先补齐缺失文件，再精简视觉内容。

先形成可运行的最小完整旅程，再调整已确认多余的区域和样式。脚本未交付时，不先重写整份 CSS、扩展分类系统或增加任务没有要求的存储模块；已有可运行旅程则直接保留。按一项业务行为及其控件、状态、文件资源一起完成，避免生成时限结束后只剩静态页面。

下载以已提供的文件 URL 或真实文件字节为依据，使用 a[download]，更名后同步下载文件名。只有元数据时不能推测下载 API，不能把 JSON、错误响应或说明字符串改成 PDF／PNG 扩展名冒充原件。固定样例在实验报告中说明来源，保留已提供文件的内容与格式；真实原件缺失时记录缺口。

上传保留用户选择的 File／Blob 字节，通过原生文件输入及真实列表完成添加和再次下载；持久化需求按任务契约选择存储。打开重命名对话框、取消、保存、刷新恢复和错误状态仍需成立，不能因减少图标文字而丢失对象或状态。

## 生成与接入

使用 imagegen 前，明确素材用途、尺寸比例、展示位置与视觉风格。透明背景需要显式指定，保存与后续处理保留透明通道。

素材存入项目静态资源目录，使用稳定路径，按展示尺寸优化分辨率和体积。信息图片提供合适的 alt，装饰图片使用空 alt；接入后检查清晰度、裁切、加载及不同视口表现。

使用宿主已有生成工具和授权路由。若宿主规定内置 imagegen 优先及 CLI 回退，遵守该路由；不添加提供方、索取无关凭据或绕过既有授权。工具失败时记录实际缺口，提示词或占位不能冒充已生成素材。

业务文字、动态数据、按钮、输入框和命中区域使用真实 DOM 与 UI 组件，图片承担视觉素材。3D/WebGL 按需复用 Three.js 等既有工具，渲染降级后仍保留信息与操作。
