# 反向审查清单

从当前任务和明确约束选择适用项目。先观察整页，再执行相应动作。某项不适用时说明业务条件，不为完成清单添加页面功能。

## 区域是否需要存在

- 同时查看应用外壳、导航、顶栏、正文和底部。当前菜单是否已经表达页标题、面包屑或说明的全部含义？删除重复表达后，连同专属容器、分隔线和预留高度检查。
- 工作区框、导航分组标题、数量、联网状态、标语、装饰尾栏分别服务什么当前任务？工作区切换、待办数量和真实错误可能有用途，静态复述不能因位置固定而默认保留。
- 账户区域是否表达可识别的实际身份及可用账户操作？头像字母不能证明用户名。示例数据与真实账户资料分开，位置遵循当前页面要求。
- 行字幕、重复状态、重复汇总和图标旁的动作文字是否提供新增信息？删除后仍需能识别对象、当前条件、操作与结果。

## 信息主次是否匹配任务

- 每个指标的含义、统计范围、单位和用途是否清楚？全量指标与当前筛选结果是否被混淆？检查零值、长数字及刷新后的真实值。
- 用户要比较的数字是否比标签、装饰和图标更突出？卡片、分组底色和留白是否帮助比较，还是把短数据拉成大空白？
- 指标卡数量、排列和图形位置按当前方案检查。不要把某页的三卡布局推广到不需要概况的列表。
- 需要同屏比较的字段是否保留、对齐并可读？长文件名、窄屏和放大后是否仍可完整查看，不能靠隐藏关键列获得简洁。

## 操作是否属于正确对象

- 页面、列表、区块和行级操作是否分别靠近所属对象？主要按钮是否与列表切换或操作栏对齐？删除文字后是否留下孤立图标？
- 同一上传动作是否占据多个常驻入口或重复拖拽区域？需要渐进展开时，检查主入口打开含拖拽与文件选择的上传 Dialog。
- 图标按钮是否语义清楚、有独立可访问名称、可见焦点和适用输入方式的提示？当前筛选和排序仍需可发现；陌生操作保留必要短文字。
- 弹层是否遮住当前要填写、比较或操作的对象？检查视口边缘、手机键盘、长文案与相邻控件，不能只看弹层自身是否完整。
- 连续打开不同弹窗后再取消或 Escape，焦点是否返回当前触发器，而非上一个弹窗的入口？保留先前交互状态复验这条实际旅程。

## 表格与数据操作是否真实

- 拖动列分隔线改变真实列宽，检查最小宽度、长文本、首末列和键盘替代。调节列宽不能误触排序，调整后行与表头仍对齐。
- 在实际视口滚动到首行和末行。确认容器边界、粘性表头和分页没有遮挡数据；焦点可进入滚动区，键盘与触屏能够到达全部内容。
- 按页面约定观察细滚动条的滚动中与停止后状态，并检查主题对比度、系统可访问设置和滚动可发现性。隐藏滚动条不能使内容不可达。
- 使用跨页数据操作上一页、下一页、页码和末页。确认列表内容、页码和禁用状态一致；筛选、排序及删除后页码有效。只有一页数据不能证明翻页有效。
- 上传文件选择和拖拽分别执行，检查真实列表项与原始字节。取消不上传，失败保留可恢复状态；成功后汇总、筛选与分页保持一致。
- 复用成熟控件时，核对实际调用与版本，再操作键盘、焦点圈、Escape 和焦点返回。包已安装或有 import 不能证明真实复用。

## 状态与输入方式是否完整

- 检查适用的加载、空数据、无匹配、失败、成功、禁用和无权限状态。错误要能恢复，输入与有效上下文要保留。
- 危险操作在实际提交前确认对象、范围和后果；取消不产生副作用。检查打开帮助和确认是否意外切换字段或提交表单。
- 桌面分别检查鼠标和键盘，手机检查轻触与滚动。将独立输入方式放在干净状态下执行，避免上一种操作污染下一项结果。
- 局部通过后再看整页。确认操作归属、主次、对齐、分组、留白与阅读顺序仍成立，不能用专项通过代替整页审查。
