# ![Beauye](assets/beauye-poster.png)

<p align="center">
面向 Coding Harness 的页面设计、执行验收与独立审查 Skill。
</p>

## 三份 Skill

| Skill | 用途 |
| --- | --- |
| [beauye-design](skills/beauye-design/SKILL.md) | 页面构图、信息取舍、视觉层级与交互方案。 |
| [beauye-execution](skills/beauye-execution/SKILL.md) | 统一任务，组织实现、测试、修复与复查。 |
| [beauye-review](skills/beauye-review/SKILL.md) | 独立检查页面，给出问题、修改建议与复验动作。 |

## 使用

按 Harness 的安装方式添加 `skills/` 中所需的目录，也可直接读取各自的 `SKILL.md`。

```text
使用 $beauye-execution、$beauye-design 和 $beauye-review，
优化素材管理页，保留现有业务。
完成设计、实现、测试和独立 Review，按发现修复并复查。
```

每份 Skill 均可独立使用。执行 CLI 需 Python 3.11+，真实工具操作由 Harness 完成。
